# voltagent/awesome-design-md — MIT License

The 71 brand-derived theme presets in `@hex-core/themes`
(`packages/themes/src/presets/*.ts`) are derived from
[voltagent/awesome-design-md](https://github.com/voltagent/awesome-design-md)
(distributed via the `getdesign` npm package). The repository ships
markdown design briefs that we parse into Hex UI `Theme` objects;
the original brief content travels alongside each theme as
`<theme>.designBrief` for downstream LLM consumption.

The original LICENSE is reproduced below verbatim per the MIT
attribution requirement. Trademark notices for individual brand
names (Tesla, Stripe, Linear, etc.) belong to their respective
owners; the presets are *style references inspired by publicly
visible design systems*, not endorsements.
